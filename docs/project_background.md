# 项目背景（基于最终报告）

## 项目名称
北京市医疗机构创新药品配备及使用模式研究。

## 政策背景
根据最终报告前言，本研究背景包括：
- 国家层面发布《支持创新药高质量发展的若干措施》（2025 年 6 月）；
- 北京市发布《北京市支持创新医药高质量发展若干措施（2025 年）》（2025 年 4 月）；
- 研究目标是支撑创新药临床应用落地与可及性提升。

## 研究目标
报告前言明确，本研究用于“全面了解创新药品在北京市医疗机构的配备使用情况”，并对创新药配备和使用特征进行量化分析。

## 数据与研究范围
报告可验证范围如下：
- 数据来源：北京市医药卫生科技促进中心提供的 2021-2023 年公立医院药品使用数据（报告原文说明源自北京市卫健委）；
- 研究对象：2019-2023 年间国家药监局批准的 111 个创新药（I 类化药和生物制品创新药）；
- 医院覆盖：北京市 513 家公立医院（一级 347、二级 74、三级 92）。

## 调研与方法背景
报告前言与调研章节可验证信息：
- 使用 Python 与 Visual Studio Code 进行量化分析；
- 组织企业调研、问卷、医院实地调研及专家咨询；
- 报告后续章节给出配备率、金额、用量、进院率、单价和治疗领域等分析结果。

## 结论与建议章节位置
最终报告在调研部分设置了“调研结论与建议”，并给出了：
- 政策协同与考核机制调整建议；
- 进院流程简化建议；
- “双通道”机制优化建议；
- 信息透明、风险监控与跨部门协同建议。
