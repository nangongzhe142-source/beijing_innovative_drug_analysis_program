# 数据目录说明

## 目录约定
- `data/raw/`：原始数据（不建议上传）
- `data/processed/`：清洗和中间数据（按需上传）

## 数据来源（按报告可验证信息）
- 2021-2023 年北京市公立医院药品使用数据（报告说明由北京市医药卫生科技促进中心提供，源自北京市卫健委）。
- 创新药名单、谈判药名单、医院分类名单等辅助文件。

## 使用限制与合规注意事项
- 可能涉及医疗机构经营与用药敏感信息，默认不公开原始明细。
- 上传前需进行脱敏与字段最小化处理，移除可识别个体或受限业务信息。
- 禁止上传包含账号、密码、Token、API Key 或内部接口地址的文件。

## 文件放置建议
- 将脚本依赖的原始文件先复制到 `data/raw/`；
- 再根据脚本路径约定建立软链接或改为统一相对路径读取；
- 处理后的结果放到 `data/processed/` 或 `outputs/`。
