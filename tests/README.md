# 测试说明

本项目以脚本分析为主，建议采用两层测试策略：

1. 结构测试（无需业务数据）
- 校验脚本注册表完整性（类别、脚本名、描述字段是否齐全）。
- 校验文档链接和关键文件存在性。

2. 数据驱动测试（需要样本数据）
- 使用脱敏的小样本数据运行单脚本，检查是否能成功输出结果文件。
- 对关键指标进行断言（如非负、分母不为零时占比合理）。

## 最小运行示例
```bash
python -m unittest tests/test_script_registry.py
python src/run_pipeline.py --list
```

## 无真实数据时的建议
- 将输入文件按脚本默认命名放置到 `data/raw/`；
- 先执行读写较小的脚本（如编码检测、注册表检查）；
- 再逐步执行统计脚本，观察输出是否生成到 `outputs/` 或项目根目录。
