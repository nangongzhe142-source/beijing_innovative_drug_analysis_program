# 数据字段字典（代码可验证版）

## 说明
- 本字段字典依据现有 Python 脚本中的列名引用整理。
- 当前仓库未包含原始数据样本文件，未能通过真实数据逐列核验的字段标记为“待确认”。

## 医院药品使用主数据（高频字段）
- `机构名称`：医院名称（A 列）。  
- `产品通用名`：药品名称（多脚本按 H 列读取）。  
- `销售金额`：销售金额字段（按列名识别）。  
- `销售制剂量`：销售用量字段（部分年份脚本也识别 `销售包装量`）。  
- `是否医保用药`：医保标识，常见取值 `Y/N`（空值通常按非医保处理）。  
- `机构等级` / `医院等级`：医院级别（部分脚本通过文件名推断一级/二级/三级）。  

## 创新药/谈判药名单数据（高频字段）
- `药品名称`：创新药名称主字段。  
- `治疗领域`：治疗领域分类。  
- `谈判药` 或 “是否谈判药”列：谈判属性标识。  
- `国产` / `进口`：来源属性。  
- `有数据`：样本可用性标记（待确认，依文件实际定义）。  

## 医院分类数据（高频字段）
- `医院名称`：医院分类名单中的标准医院名称。  
- 医院类型标签：`委属`、`市属`、`其他`（具体字段名待确认，脚本中存在直接规则赋值和名单匹配两种方式）。

## 分析过程衍生字段（脚本生成）
- `year` / `年份`：数据年份。  
- `hospital_level` / `医院级别`：一级/二级/三级。  
- `hospital_category` / `医院分类`：委属/市属/其他。  
- `is_insurance`：医保药/非医保药。  
- `is_innovative` 或 `是否创新药_清理`：创新药标识。  
- `matched_innovative_drug` / `匹配的创新药名称`：匹配后的标准药品名。  
- `进院医院数`、`医院总数`、`平均进院率`：进院率计算核心字段。  

## 指标输出字段（高频）
- `总销售金额（元）`、`销售金额_亿元`、`销售金额_万元`  
- `总销售制剂量`、`医院用量_亿`、`医院用量_万`  
- `排名`、`前十名/后十名`相关字段  

## 待确认字段
- 某些脚本按列位置读取（如 O 列、Y 列），但字段名可能随年份或数据导出版本变化。  
- 少量脚本中引用了外部模块（如 `data_preprocessor`、`drug_matcher`）对应中间字段需结合缺失文件补充确认。
